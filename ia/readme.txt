Classificação automática (Inteligência Artificial)
O sistema deverá utilizar um modelo de Machine Learning previamente treinado para
classificar cada leitura recebida.
A classificação deverá possuir, no mínimo, três categorias, por exemplo: Ruim, Médio, Bom,
ou outra classificação coerente com a proposta do grupo.

OBRIGATÓRIO:
● Utilização de um modelo de classificação.
● Classificação automática para cada nova leitura
