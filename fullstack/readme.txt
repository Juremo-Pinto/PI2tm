Servidor Web (Desenvolvimento de Aplicativos)
- O servidor deverá disponibilizar uma API REST capaz de:
i. receber as leituras enviadas pela aplicação C#;
ii. encaminhar essas informações para o módulo de Inteligência Artificial;
iii. retornar ao cliente o resultado da classificação;
iv. disponibilizar os dados necessários para visualização no frontend.
- A comunicação deverá utilizar HTTP e JSON.

OBRIGATÓRIO:
● Endpoint para recebimento das medições.
● Chamada do algoritmo de IA.
● Retorno da classificação ao cliente


Interface Web (Desenvolvimento de Aplicativos)
- O sistema deverá disponibilizar uma página Web contendo, no mínimo:
i. valor atual da leitura;
ii. classificação retornada pelo modelo de IA;
iii. histórico das últimas leituras recebidas;
iv. indicação visual do estado atual do sistema.
- A interface deverá ser atualizada conforme novas medições forem realizadas.

Obrigatório:
● leitura atual;
● classificação;
● histórico das últimas medições;
● horário da última atualização.
