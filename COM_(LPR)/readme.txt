Comunicação com servidor (Linguagens de Programação)
Uma aplicação desenvolvida em C# deverá:
i. estabelecer comunicação com a Porta COM;
ii. receber continuamente as leituras provenientes do STM32;
iii. organizar e tratar as informações recebidas;
iv. converter os dados para o formato JSON;
v. realizar requisições HTTP para o servidor desenvolvido pelo grupo.

OBRIGATÓRIO:
● Leitura contínua da Porta COM.
● Conversão das informações para JSON.
● Envio das medições para a API
